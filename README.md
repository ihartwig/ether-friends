# ether-friend
Custom-purpose and hackable ethernet adapters

[papoe-pi-zero](papoe-pi-zero) Pi Zero HAT with FRC-compatible passive PoE 100M usb-ethernet adapter
[xdg201-carrier-base](xdg201-carrier-base) XDG201 Xtreme10G ethernet switch module carrier board

The projects in this repository need KiCAD 9 or later to open them.
